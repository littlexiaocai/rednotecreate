## 内容结构方法论：观点先说还是后说？

### 结论

**有反转就藏着观点，没反转就先亮出观点。**

### 分层框架

```
广告（封面/标题）→ 让人点进来
故事（正文）     → 让人经历情感过程
观点（结论）     → 让人带走价值
```

观点是故事之后自然生长出来的东西，是**产品的结晶**，不是广告，也不是产品本身。

### 为什么第一点必须先讲故事

第一点有天然的反转结构：
- 我以为男友妈妈会劝我去理解我妈、哄我妈
- 但她说的完全相反：「这不是你妈一手造成的吗？」

这个反转是整段的力量所在。提前说观点 = 把答案先说出来，悬念消失，故事冲击力归零。

同样一句观点，进入通道不同，效果完全不同：
- **提前说**：观众用逻辑评判（「这说法对不对？」）
- **故事后说**：观众用感受接收（「对，就是这样」）

### 知识库佐证

- `2026Q1_158`：「标题不需要展开你的选题，而是需要包装你的选题」
- `2026Q1_176`：「封面和标题是广告，正文是产品」
- dbs-hook 原则：「好开头制造悬念，不直接给答案」——观点就是那个答案，藏到最后

## 视频文字提示策略（2026-03-25）

### 结论：不需要全程文字导航

这条视频是情感内容，不是教程。两种内容对文字提示的需求完全不同：

| | 教程/干货类 | 情感/叙事类 |
|---|---|---|
| 信息密度 | 高，需要标记 | 低，靠情绪带动 |
| 观众状态 | 记笔记模式 | 共情模式 |
| 文字作用 | 导航 | 放大情绪 |

过多文字提示会打断观众进入情绪的节奏，变成在上课。

### 4分钟够不够撑？

够。结构本身已经帮观众做了导航：
- 字幕卡负责切换信号（真放下 / 不期待 / 去沟通）
- 第一点的故事本身有起承转合，不会跟丢
- 你和男友的对话来回切换，本身有节奏感

### 文字出现的唯一理由

文字只在**情感高点**出现，用来放大，不是用来导航：

1. 男友妈妈那句话 →「跟妈妈不亲，不是你不孝，是父母造成的」打字幕强调
2. 男友说「放下是自然发生的那瞬间」→ 可以打
3. 其他地方 → 不需要

### 关键引言的文字出现时机

随口播同步出现，不要提前打在画面上等着。建议拆成两行：
- 第一行随「在嫌孩子不孝顺之前」出现：`跟妈妈不亲，不是你不孝`
- 第二行随「先看看自己过去是怎样对孩子的」出现：`是父母造成的`

字要大，白字或黑字，不需要装饰。
