> 多来源、持续生长的知识底座。边读边存，Agent 越用越强。

## 入库规则

### 卡片格式

```
### [简短标题]
- **来源**：[书名/文章/播客/访谈/推文] | [具体章节或链接]
- **类型**：原则 / 方法论 / 真实故事 / 金句
- **核心观点**：[一句话，不超过 30 字]
- **原文**：[原话或精确转述]
- **场景标签**：#决策 #心理 #产品 #表达 [可多选]
```

### 来源类型

| 代号 | 说明 | 示例 |
|---|---|---|
| 📖 | 书籍 | 《Elon Musk》Walter Isaacson |
| 🎙️ | 播客/访谈 | Lex Fridman Podcast #252 |
| 🐦 | 推文/社交媒体 | @elonmusk 2024-03-15 |
| 📰 | 文章/报道 | Bloomberg 2024-01-20 |
| 🎬 | 视频/演讲 | TED 2022、SpaceX 全员会议 |
| 📝 | 个人笔记 | 自己读完后的提炼 |

### 快速入库流程

看到好内容时，只需要回答 4 个问题：
1. **他说了什么？**（原文）
2. **一句话概括？**（核心观点）
3. **这是什么类型的知识？**（原则/方法论/故事/金句）
4. **用户问什么问题时该调用它？**（场景标签）

丢进对应的场景板块即可。编号不重要，内容重要。

### 去重规则

- 同一个观点从不同来源出现 → 合并到一张卡片，来源列多个
- 同一个故事的不同细节 → 保留为独立卡片，互相补充
